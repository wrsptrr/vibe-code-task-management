## Melakukan Perubahan Kode, File, Folder dan lain-lain

- Sebelum melakukan coding harus dilakukan plan terlebih dahulu
- Saat melakukan planing, hasil plan disimpan sebagai file di folder /docs/plan/, file ini digunakan sebagai acuan saat coding
- Format nama file plan: YYYY-MM-DD-nama-plan.md (contoh: 2026-11-01-ubah-aturan-plan.md)
- Jangan masukan folder docs/plan/ ke git
- Setelah membuat plan, buka file plan tersebut dan langsung tampilkan di preview
- Eksekusi code setelah aku perintahkan untuk mengeksekusi plan terkait
- Saat mengeksekusi plan, pindah ke branch dulu sesuai dengan perintah (jika branch belum ada, buat branch baru dengan nama yang sesuai)
- Tanyakan dulu sebelum menambah dependency baru, atau mengubah struktur folder.
- Perbarui file ini bila tech stack, struktur, atau perintah berubah.
- Perubahan jangan langsung di git commit
