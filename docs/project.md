**Task Manajemen** — aplikasi untuk membuat, mengatur, dan memantau tugas.

### Fitur Utama

- Task Management
  - CRUD tugas (judul, deskripsi, status, prioritas, deadline)
  - Status tugas: `todo` → `in_progress` → `done`
  - Filter & pencarian tugas

- Report
  - per-day
  - per-week
  - per-month
